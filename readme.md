# 🌿 Bem-vindo ao EcoTrend!

Imagine que você tem uma loja de verdade, mas ela vive dentro do computador. O **EcoTrend** é exatamente isso! É uma loja virtual (um e-commerce) focada em vender produtos super legais que ajudam a cuidar do nosso planeta, como escovas de bambu e regatas ecológicas.

## 🛠️ Como usamos nossas Ferramentas

* **HTML:** Usado para criar e interligar os arquivos das nossas páginas (Início, Categorias, Detalhes e Contato), organizando exatamente onde entra a foto da Camisa de Algodão, o texto do Kit de Escovas de Bambu e os botões.
* **CSS:** Usado para importar a fonte 'Poppins' e aplicar os tons de verde que combinam com a pegada ecológica da loja, além de formatar o fundo do site para destacar os produtos.
* **Bootstrap 5 & Grid Layout:** O Bootstrap nos forneceu os componentes visuais (como o menu superior, o formulário de contato e o carrossel). O *Grid Layout* foi usado para organizar as caixinhas (Cards) dos produtos lado a lado, garantindo que eles se ajustem sozinhos — exibindo 3 por linha no monitor e apenas 1 por linha na tela do celular(responsividade).
* **JavaScript:**Pequeno código usado para dar vida ao contador do carrinho no topo da página. O código soma +1 toda vez que você clica em "Adicionar" e utiliza o *localStorage* do navegador para salvar essa quantidade mesmo quando você muda de uma página para outra.

## ✨ O que essa loja sabe fazer?

* **Páginas Conectadas:** Você pode passear pela Página Inicial, ver as listas nas Categorias, conferir a tela de Detalhes de um produto e até preencher um formulário na página de Contato.
* **Carrinho com Memória:** Se você colocar um Shampoo de Babosa no carrinho, o site não esquece! Ele anota esse número em um caderninho secreto do navegador (chamado *localStorage*), então o seu carrinho continua cheio mesmo se você mudar de página.
* **Tudo se Move:** O site tem um menu que desce ao clicar (dropdown), abas que abrem e fecham como uma sanfona (accordion) para mostrar os detalhes do produto, e imagens que passam sozinhas na página inicial.
